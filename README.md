# 🐅 NAQQASH - Hand Cricket 24/7 Cloud Deployment

Deploy this server to **Render.com** (Free) so it runs 24/7 permanently, even when your PC is turned off!

---

## 🚀 3-Minute Free Setup on Render.com:

1. Go to **[https://dashboard.render.com](https://dashboard.render.com)** and Sign Up / Log In (Free).
2. Click the **"New +"** button in the top right and select **"Web Service"**.
3. Choose **"Build and deploy from a Git repository"** OR upload this repository.
   *(Or connect your free GitHub account, create a new repo named `naqqash-hand-cricket`, and drag & drop these files into it).*
4. Fill in these simple fields:
   - **Name:** `naqqash-hand-cricket`
   - **Region:** Any (e.g. Frankfurt / Singapore)
   - **Runtime:** `Node`
   - **Build Command:** `npm install --production`
   - **Start Command:** `node server.js`
   - **Instance Type:** `Free` ($0/month)
5. Click **"Deploy Web Service"**! 🚀

---

## 🌐 What Happens After Deployment:

- You will get a permanent, 24/7 live URL like:
  **`https://naqqash-hand-cricket.onrender.com`**
- Anyone can open this link directly in their browser or mobile to play.
- Anyone can download the APK directly from:
  **`https://naqqash-hand-cricket.onrender.com/Naqqash.apk`**
- You can turn off your PC completely — cousins can still play anytime!
